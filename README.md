# Simple Stock Tracker in Python

A beginner-friendly Python application that allows users to track stock investments using predefined stock prices. The program calculates the total value of selected stocks based on user-entered quantities and generates an investment summary.

Users can enter multiple stock symbols, view individual investment values, calculate the total portfolio value, and optionally save the results to a text report file for future reference.

## Features

* Predefined stock price database
* User input for stock symbols and quantities
* Calculates individual stock investment values
* Displays total portfolio investment
* Handles invalid stock symbols
* Generates and saves investment reports to a text file
* Simple command-line interface

## Technologies Used

* Python 3
* Dictionaries
* Loops and Conditional Statements
* File Handling

## How It Works

1. The user enters the number of stocks to track.
2. For each stock, the user provides the stock symbol and quantity.
3. The program checks whether the stock exists in the predefined database.
4. Investment values are calculated automatically.
5. The total portfolio value is displayed.
6. Users can save the investment report as `stock_report.txt`.

## Sample Supported Stocks

* AAPL (Apple)
* TSLA (Tesla)
* GOOG (Google)
* AMZN (Amazon)
* MSFT (Microsoft)

This project is ideal for beginners learning Python concepts such as dictionaries, loops, user input, calculations, data storage, and file handling.
